# play-spec-FE

Frontend for [PlaySpec](https://github.com/MKarapiperakis/PlaySpec) —1 upload an OpenAPI/Swagger
spec, validate it, and generate a Playwright test project from it.

Stack: React + TypeScript (Vite), Tailwind CSS + shadcn/ui, TanStack Query, React Router,
react-hook-form + zod, react-dropzone, sonner.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build     # type-check + production build
npm run preview   # serve the production build locally
npm run lint       # oxlint
```
